У ИЛЕМ 4.0 — ОТЧЁТ О СБОРКЕ ПАПКИ
====================================

СОЗДАНО
-------
- Новая самостоятельная папка U_Ilem_4_0 в корне репозитория.
- U_Ilem_4_0.html — отдельная копия исходного U_Ilem_3_2.html.
- U_Ilem_4_0_server.js — сервер, который обслуживает файлы только из
  текущей папки и открывает локальный HTML из этой же папки.
- U_Ilem_4_0_lighting.js — система освещения, перенесённая из ранее
  подготовленного комплекта без изменения её исходного содержимого.
- Версионированные BAT, VBS, README, отчёт и файлы иконок.

ИСПРАВЛЕНИЯ УПАКОВКИ
-------------------
- Сервер больше не использует путь ../U_Ilem_3_2.html.
- Главная страница — U_Ilem_4_0.html в текущей папке.
- Модуль освещения загружается из U_Ilem_4_0_lighting.js.
- Порт новой сборки — 4320, чтобы не пересекаться с прежним комплектом
  на порту 4317.
- Проверки BAT-файла соответствуют именам файлов версии 4.0.
- Все runtime-файлы для запуска находятся в этой папке.

СОХРАННОСТЬ
-----------
- Исходный U_Ilem_3_2.html в корне репозитория не изменён.
- Утверждённая карта U_Ilem_3_0_APPROVED_MAP.html не изменена.
- Старая папка U_Ilem_Complete не удалена и не переименована.
- Существующая резервная ветка не изменена.

ПРОВЕРКИ И ОГРАНИЧЕНИЯ
---------------------
- Состав файлов новой папки и SHA исходного HTML проверяются через GitHub.
- Файлы запуска и сервера подготовлены для автономной папки.
- Реальный запуск BAT на Windows, визуальная проверка игры в браузере,
  действия пользователя, сохранение игры и работа Ollama в среде
  пользователя не проверены.
- Этот отчёт не означает, что полная приёмка игрового функционала
  версии 4.0 завершена.

ВАЖНО
-----
Дальнейшую разработку вести внутри U_Ilem_4_0.

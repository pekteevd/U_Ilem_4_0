У ИЛЕМ 4.0 — РАБОЧАЯ СБОРКА
============================

СТРУКТУРА
---------
U_Ilem_4_0.html                 Точка входа.
U_Ilem_4_0_base.html            Изолированная игровая база 3.2 для версии 4.0.
U_Ilem_4_0_server.js            Локальный сервер и сборщик страницы.
U_Ilem_4_0_lighting.js          Освещение.
U_Ilem_4_0_ecology.js           Жизненный цикл деревьев и кустарников.
U_Ilem_4_0_water.js             Водоснабжение и автополив.
U_Ilem_4_0_production.js        Мастерская и изготовление предметов.
U_Ilem_4_0_construction.js      Проекты и четыре строительных этапа.
U_Ilem_4_0_repairs.js           Карта, календарь, единая привязка задач и этапов.
U_Ilem_4_0_operations.js        Осмотры, дефекты и сводная закупка.
U_Ilem_4_0_ollama.js            Подключение командного чата к локальной Ollama.
U_Ilem_4_0_3d.js                Объёмная карта на Three.js.
Start_U_Ilem_4_0.bat            Запуск в Windows.
CreateShortcut_U_Ilem_4_0.vbs   Создание ярлыка.
CHECK_REPORT_U_Ilem_4_0.txt     Технический отчёт.

Утверждённая карта U_Ilem_3_0_APPROVED_MAP.html должна находиться
в корне репозитория, на один уровень выше папки U_Ilem_4_0.
Сервер извлекает из неё изображение и использует его в игровой карте.
Не заменяй этот файл старой картинкой или картой из базы 3.2.

ЗАПУСК
------
1. Установи Node.js LTS: https://nodejs.org/
2. Сохрани структуру репозитория: папку U_Ilem_4_0 и файл
   U_Ilem_3_0_APPROVED_MAP.html рядом с ней.
3. Запусти Start_U_Ilem_4_0.bat.
4. Откроется http://127.0.0.1:4320/U_Ilem_4_0.html.
5. Не закрывай окно локального сервера во время игры.

Внешние npm-пакеты для локального сервера не требуются.
Для объёмного режима браузеру нужен доступ к CDN Three.js.
Если интернета нет, обычная игровая карта продолжит работать,
но 3D-режим не загрузится.

ЧТО ВХОДИТ В ВЕРСИЮ
-------------------
Базовая игра: календарь, погода, команда, навыки, энергия, склад,
ресурсы, финансы, строительство, проекты, события, хроника,
командный чат, общая доска задач и управление камерой.

Карта: в игровой сцене используется утверждённое изображение.
Маркеры объектов и пользовательские постройки остаются интерактивными.
Движущаяся световая полоса поверх карты отключена.

Задачи и календарь: запись из календаря создаёт задачу с тем же ID
в общей доске. Добавленная рекомендация исчезает из списка предложений.
Снятая с плана задача сохраняется в истории со статусом «Снята с плана».

Этапы: просмотр работ ограничен выбранным объектом. Открытие этапа
выполняется по его ID; этап другого объекта не подставляется автоматически.
Создание нового этапа — отдельное действие с заранее привязанным объектом.

Осмотры и дефекты: история осмотров и карточки дефектов привязаны
к объекту. Из дефекта можно создать задачу с материалами и приоритетом.

Склад: сводная закупка объединяет одинаковые материалы из активных задач,
этапов и дефектов, вычитает остатки и отдельно подтверждает списание денег.

Локальный ИИ: командный чат обращается к серверному API Ollama.
По умолчанию используется модель qwen3:4b. Модель не входит в репозиторий.
Для проверки есть кнопка «Проверить Ollama». ИИ предлагает черновики,
но не списывает ресурсы и не отмечает работу выполненной.

Объёмная карта: отдельный 3D-режим строит геометрию домов, крыш,
деревьев, грядок, дорожек, ограждений и водоёма. В 3D можно вращать
камеру, приближать сцену и выбирать объекты.

Редактор внутренних планировок в активную сборку 4.0 не подключается.
Производство мебели и её учёт в складских данных не удаляются.

СОХРАНЕНИЯ
----------
Версия 4.0 использует ключ uilem4save. Старый ключ uilem3save
может использоваться только для первичной миграции.
Перед первым запуском новой сборки экспортируй старый игровой мир.

ПРОВЕРКИ
--------
В папке игры доступны модульные тесты:
node U_Ilem_4_0_water.test.js
node U_Ilem_4_0_production.test.js
node U_Ilem_4_0_ecology.test.js
node U_Ilem_4_0_construction.test.js

Синтаксические и модульные тесты не заменяют запуск BAT и визуальную
проверку Chrome на компьютере пользователя.

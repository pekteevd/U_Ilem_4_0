У ИЛЕМ 4.0
===========

ЗАПУСК
1. Установи Node.js LTS, если он ещё не установлен.
2. Распакуй папку U_Ilem_Complete целиком.
3. Запусти Start_U_Ilem.bat.
4. Оставь открытым окно локального сервера. Игра откроется в браузере по адресу http://127.0.0.1:4317.

АРХИТЕКТУРА
- Основой игровой логики служит U_Ilem_3_2.html из корня репозитория.
- Сервер открывает этот файл как главную страницу и подключает lighting.js.
- Исходный HTML игры и утверждённая карта не переписываются.
- Сохранения остаются локальными в браузере.

ОСВЕЩЕНИЕ
Во вкладке «Освещение» доступны покупка двух типов тёплых гирлянд, подвесного фонаря, садового фонаря на стойке, настенного и солнечного фонаря; склад купленных предметов; установка щелчком по точке карты; снятие с возвратом на склад; автоматический, постоянный и выключенный режимы; дневной, вечерний и ночной вид; учёт мощности и расчётного потребления; расчёт ежемесячной оплаты при подключении к электросети.

Электрическая мощность и тариф пока являются игровыми параметрами, а не инженерной моделью реальной проводки. Солнечные фонари автономны. Новые модели можно добавлять в каталог без изменения координат карты.

СОХРАНЕНИЯ
Игра использует локальное сохранение браузера. Для переноса на другой компьютер используй встроенный экспорт/импорт. Перед обновлением сборки экспортируй текущее сохранение.

ПРОВЕРКА
Сборка основана на существующей версии 3.2 и дополнена системой освещения. Фактический запуск в Windows на устройстве пользователя из этой среды выполнить невозможно. После первого запуска проверь отображение карты, сохранение, покупку и установку светильников.

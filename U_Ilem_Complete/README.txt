У ИЛЕМ — КОМПЛЕКТ ЗАПУСКА
========================

СОСТАВ ПАПКИ
------------
U_Ilem.html         Игровой файл
server.js           Локальный сервер и мост к Ollama (Node.js, без npm-зависимостей)
Start_U_Ilem.bat    Основной запуск игры
CreateShortcut.vbs  Создаёт ярлык Windows с марийской иконкой
U_Ilem.ico          Иконка ярлыка в стиле марийского орнамента
U_Ilem_icon.png     Большая версия значка

КАК ЗАПУСТИТЬ
-------------
1. Распакуйте все файлы в одну папку, например C:\Games\U_Ilem.
2. Убедитесь, что установлены Node.js и Ollama.
3. В Ollama должен быть установлен qwen3:4b (в вашем случае он уже установлен).
4. Дважды щёлкните Start_U_Ilem.bat.
5. Откроется браузер с игрой. При первом запуске BAT создаст рядом ярлык «У Илем.lnk» с иконкой.
6. В дальнейшем можно запускать игру двойным щелчком по ярлыку «У Илем».

ИНТЕГРАЦИЯ ИИ
-------------
Игра обращается к локальной Ollama через Node.js на 127.0.0.1:4317.
Модель: qwen3:4b. Платный API и облачный ИИ не используются.
Для освобождения оперативной памяти Ollama получает keep_alive=90s.
Если приложение Ollama закрыто, игра продолжит работать без ИИ, но команды чата не будут обработаны до запуска Ollama.

3D-КАРТА
--------
Основная карта построена на WebGL2, без Three.js, внешних 3D-библиотек и внешних текстур.
Для вращения перетаскивайте карту мышью. Для масштаба используйте колесо мыши, кнопки +/− или жест двумя пальцами.
Нажимайте на дома или на кнопки объектов под картой, чтобы открыть карточку объекта и приблизить камеру.

СОХРАНЕНИЯ
----------
Игра использует локальное хранилище браузера для адреса http://127.0.0.1:4317.
Старые сохранения, созданные при открытии HTML двойным щелчком (file://), браузер может хранить отдельно от новой версии.
Старые файлы не удаляются и не перезаписываются. При необходимости откройте прежнюю игру, экспортируйте резервную копию и импортируйте её в новую сборку.

ПРИМЕЧАНИЕ
----------
Не закрывайте окно «У Илем - локальный сервер», пока игра открыта.
Для остановки локального сервера закройте это окно.
Сервер привязан к 127.0.0.1 и не открыт для других устройств в вашей сети.

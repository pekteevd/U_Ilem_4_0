## Принципы
- Новая архитектура, не косметический патч 4.0.
- Windows, локальный запуск.
- Телефон отложен.
- Godot не используется.
- Утверждённая карта не заменяется и не запрашивается повторно.
- Один основной комплект файлов, без множества параллельных версий.
- Проверка кода не выдаётся за проверку игры в браузере.

## Состояние на 4 ноября 2026
**Статус: документация создана.** Проектная папка и документы аудита готовы. Игровой runtime 5.0 ещё не создан. Следующий этап: закончить аудит старого ядра, зафиксировать архитектурные решения и создать минимальное вертикальное ядро.

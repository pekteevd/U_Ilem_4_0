У ИЛЕМ 4.1 · ПОЛНАЯ РАБОЧАЯ СБОРКА
=====================================

ЗАПУСК НА WINDOWS
-----------------
1. Распакуй всю папку U_Ilem_4_1 в удобное место.
2. Убедись, что установлен Node.js (LTS или v24+).
3. Запусти START_U_ILEM_4_1.bat двойным щелчком.
4. Дождись открытия браузера по адресу http://127.0.0.1:4321/U_Ilem_4_1.html.
5. Не закрывай окно локального сервера, пока игра открыта.

Внешние npm-пакеты не нужны. Сервер слушает только 127.0.0.1 и доступен с этого компьютера.

СОСТАВ
------
- U_Ilem_4_1_base.html — игровая основа 4.0, адаптированная сервером как 4.1.
- U_Ilem_4_1_server.js — локальный сервер, отдельный ключ сохранения и Ollama API.
- U_Ilem_4_1_visual_base.png — единственная утверждённая основная карта.
- U_Ilem_4_1_lighting.js — освещение.
- U_Ilem_4_1_interiors.js — редактор внутренних планировок и мебели.
- U_Ilem_4_1_ecology.js — деревья, кустарники и сезонный цикл.
- U_Ilem_4_1_water.js — водоснабжение и полив.
- U_Ilem_4_1_production.js — мастерская и производство.
- U_Ilem_4_1_construction.js — строительство по этапам.
- core/work-items.js — единый реестр работ, миграция старых записей и подбор исполнителя.
- ai-bridge.js — командный чат с Ollama, черновики задач, календарь и три ручных слота.
- tests/ — автоматические проверки.

СОХРАНЕНИЯ
----------
Автосохранение использует новый ключ uilem4_1save.
При первом запуске читаются сохранения uilem4save и uilem3save, если нового сохранения ещё нет. Старые ключи не удаляются и не перезаписываются.
Три ручные ячейки находятся отдельно. В игре нажми «Слоты сохранения».

OLLAMA
------
Для интеллектуального командного чата нужна Ollama и модель qwen3:4b.
Установи и запусти Ollama отдельно, затем скачай модель командой:
ollama pull qwen3:4b

Игра запускается и без Ollama. В этом случае обычная игровая логика доступна, а командный ИИ сообщает, что модель недоступна. Игра не подменяет ответ ИИ фиктивным результатом.

ПРОВЕРКИ
--------
Из папки игры:
node --check U_Ilem_4_1_server.js
node --check ai-bridge.js
node --check core\work-items.js
node tests\work-items.test.js
node U_Ilem_4_1_interiors.test.js
node U_Ilem_4_1_water.test.js
node U_Ilem_4_1_production.test.js
node U_Ilem_4_1_ecology.test.js
node U_Ilem_4_1_construction.test.js

ОГРАНИЧЕНИЯ
-----------
Ollama и модель не входят в архив и устанавливаются отдельно.
Трёхмерный режим, если он запрашивает внешнюю библиотеку, может требовать интернет. Основная карта загружается локально из PNG.
Это сборка для локальной проверки на одном компьютере, не сетевой многопользовательский режим.

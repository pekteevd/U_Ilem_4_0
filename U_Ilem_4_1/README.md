# У Илем 4.1 · рабочая сборка

Это отдельная линия разработки в ветке `work/u-ilem-4-1`.

**Сейчас это не готовая игра и не самостоятельный релиз.** Исходная сборка 3.3 хранится как материал для переноса и сравнения. Её нельзя считать версией 4.1.

## Состав рабочего каталога

- `core/work-items.js` — единая модель работ и миграция старых записей.
- `tests/work-items.test.js` — автоматические тесты модуля.
- `docs/AUDIT_3_3.md` — результаты проверки исходной сборки.
- `docs/DATA_MODEL_4_1.md` — контракт новой модели данных.
- `source/legacy-3.3/` — неизменённые материалы предыдущей сборки.
- `source/U_Ilem_3D_fixed_work.zip` — исходный архив.

## Проверка модуля

Требуется Node.js. Из корня папки:

```bat
node tests/work-items.test.js
```

Ожидаемый результат: `work-items tests: OK`.

## Важное

Не удалять `U_Ilem_4_0`, `U_Ilem_5_0` и другие исходники до полной миграции, тестирования сохранений и создания проверенного релизного ZIP 4.1.

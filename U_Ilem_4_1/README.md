# У Илем 4.1

Полная локальная Windows-сборка на базе проверяемой игровой линии 4.0. Все файлы запуска, игровые модули и утверждённая карта находятся в этой папке.

## Запуск
Распаковать всю папку и запустить `START_U_ILEM_4_1.bat`. Требуется Node.js 22 LTS или новее. npm-пакеты не требуются. Игра открывается на `http://127.0.0.1:4321`.

## Что входит
- Основная игровая система: команда, календарь, погода, объекты, проекты, склад, финансы, задачи и карта.
- Строительство с этапами, мастерская и производство, редактор интерьеров, освещение, водоснабжение, сад и экология.
- Единственная утверждённая карта `U_Ilem_4_0_visual_base.png`, используется исходный файл без замены и перерисовки.
- Локальный сервер с API Ollama. Командный чат получает реальный ответ модели и создаёт черновики от 3 до 8 задач. При ошибке Ollama черновики не подменяются шаблонным ответом.
- Единый реестр работ: задачи, сезонные пункты календаря и этапы объектов попадают в общую доску; календарь показывает те же сезонные записи.
- Автосохранение в отдельный ключ `uilem4_1save`, чтение сохранений 4.0/3.x без перезаписи старых ключей, три ручных слота и экспорт резервной копии.

## Ollama
Для командного ИИ отдельно установи Ollama и модель `qwen3:4b`:
```powershell
ollama pull qwen3:4b
```
Игра запускается и без Ollama, но командный ИИ будет недоступен.

## Проверки
Автоматические тесты и сборка ZIP запускаются GitHub Actions на ветке `work/u-ilem-4-1`. Локальные команды перечислены в `README_U_Ilem_4_1.txt`.

## Важное
Сборка рассчитана на одного пользователя и локальный компьютер. Старые версии репозитория не удаляются до отдельной проверки сохранений и подтверждения результата на ноутбуке.
